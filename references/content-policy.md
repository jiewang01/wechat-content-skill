# 内容合规红线（Content Policy）

本文定义 wechat-content-skill 的内容合规基线：敏感内容约束、引用规范、免责边界。被 [../skills/content/SKILL.md](../skills/content/SKILL.md)（写作侧）与 [../skills/quality/SKILL.md](../skills/quality/SKILL.md)（校验侧）共同引用。

与 [adversarial-constraints.md](adversarial-constraints.md) 的分工：H 系列约束**对抗协作的行为**（谁产出、谁攻击、谁裁决），本文约束**内容本身**（什么能写、怎么引用、如何免责）。

三层强度：

| 层 | 约束 | 执行方式 |
|----|------|----------|
| 硬红线 | 敏感内容（第一节） | 不产出即合规，产出即违规；宁可弃稿 |
| 机器强制 | 引用规范（第二节） | 内容门 error 拦截 |
| 写作自律 | 免责边界（第三节） | Defender 自审 + 人工复核 |

## 一、敏感内容约束（硬红线）

以下内容一律不产出，无论用户如何要求；触发时向用户说明原因并给出合规替代方向：

| 类别 | 红线 | 处理 |
|------|------|------|
| 违法违规 | 赌博、色情、暴力血腥、毒品、诈骗等法律明令禁止的内容 | 拒绝产出，说明理由 |
| 政治谣言 | 未经核实的政治类传闻、攻击性表述 | 不产出；客观政策解读必须引用权威来源 |
| 医疗健康 | 疾病诊断、处方建议、疗效承诺 | 降格为信息参考（见下） |
| 金融投资 | 个股买卖建议、收益承诺 | 降格为信息参考 |
| 法律 | 对具体案件给出法律结论 | 降格为信息参考 |

**「降格为信息参考」的统一格式**：陈述事实 + 标注来源与时点 + 免责提示（如「以上为公开资料整理，不构成投资建议」「不能替代专业医疗意见」「具体请咨询执业律师」），**不给行动指令**。

## 二、引用规范（机器强制）

引用一致性由内容门机器复核（[../skills/quality/rules/content.md](../skills/quality/rules/content.md)），违规即 error：

- `unknown_fact_ref`：正文引用了研究产物中不存在的 `fact_id` —— 一切事实必须能在 `ResearchResult.facts` 中溯源；
- `unknown_source_ref`：`fact` 的 `source_ids` 指向不存在的信源 —— 事实与信源一一挂钩。

机器检查不到、靠写作纪律补足的部分：

1. **数据四要素**：数字、单位、时点、来源，缺一不发——「去年大幅增长」不是可发布的数据；
2. **观点归因**：判断性表述要么是明示的作者观点，要么标注来源（「据 XX 报道」）；匿名转述（「业内人士透露」）不作为事实依据；
3. **信源分级**：遵循 [../skills/research/references/source-credibility.md](../skills/research/references/source-credibility.md)——关键论断需一级信源，或两个独立二级信源交叉验证；
4. **不编造**：研究产物里没有的内容，写作阶段不补——宁可留白，不可脑补（根 SKILL.md 规则第一条）。

## 三、免责边界（写作侧自律）

机器不检查免责声明，但以下场景必须在成稿中体现：

| 场景 | 要求 |
|------|------|
| 演绎案例 | 虚构 / 化名案例明示「案例为演示目的构造」或使用化名标注 |
| 预测类内容 | 给出依据与不确定性说明；禁用确定性口吻（「必将」「一定」） |
| 教程实操 | 涉及数据删除、资金操作、系统配置的步骤，就近标注风险与不可逆性 |
| 引用第三方内容 | 显著引用注明出处；长段转载需授权，未授权不转 |

免责声明的位置遵循**就近原则**：提示跟在对应内容旁边，而不是全文末尾一句兜底。

## 四、与质量门的关系

| 约束 | 执行方式 | 违规后果 |
|------|----------|----------|
| 引用一致性（第二节） | 内容门机器复核（`unknown_fact_ref` / `unknown_source_ref`） | error，拦截状态机推进 |
| 事实编造 | `fact_id` 溯源机制 + 研究 / 写作阶段分离 | error，拦截推进 |
| 敏感内容（第一节） | 写作与规划侧判断（本文约束 LLM 行为） | 不产出即合规 |
| 免责边界（第三节） | 写作侧自律 + 人工复核 | 无机器拦截，靠 Defender 自审 |

诚实边界：合规判断的最后一环永远是人工——本技能的机器只能强制「引用可溯源、事实不编造」，不能替代法律与平台审核的判断。
