# 公众号 SEO 参考（SEO Reference）

公众号的自然流量入口，除会话与朋友圈分享外，还有「搜一搜」。本文从标题、摘要、关键词、搜一搜收录四个维度约束 Agent 的写作侧决策，并与产物字段一一对应。

定位：**SEO 是参考，不是质量门**。`validators/` 没有任何 SEO 检查项——平台搜索算法未公开，任何「最优关键词密度」都是编造；确定性工具只检查可确定的事（H8 精神）。本文的全部建议都不拦截发布，作用于写作与规划决策。

## 一、标题（title）

**字段链路**：`ArticleDraft.title` → `ContentPackage.title` → `WechatDocument.title`。`WechatDocument.html` 是片段、不携带标题，标题随产物单独交付，发布时写入草稿箱标题栏。

**自动生成**：成稿阶段 `_extract_title()`（`core/workflow/pipeline.py`）取正文第一个 H1 的文本；没有 H1 时退化为第一个非空行（剥掉 `#` 前缀），再兜底「未命名文章」。有意义的 H1 就是有意义的默认标题。

**平台限制**：标题最长 64 字（以草稿箱接口当前限制为准）。管线不截断标题，超长会在发布接口被拒——长度控制在写作阶段完成。

**拟标题规则**（按优先级）：

1. **主关键词前置**：信息流与搜索结果都会截断长标题，核心词放前 20 字；
2. **兑现 brief**：标题是 `ContentBrief.topic` 的具体化，兑现 `goal` 的承诺——内容门拦得住无据论断，拦不住货不对板，这层对齐靠写作自律；
3. **具体优于空泛**：数字、专有名词、结果物优于形容词堆叠；
4. **不做标题党**：夸张承诺与堆砌惊叹号损害账号长期可信度。

## 二、摘要（digest）

**字段链路**：`ArticleDraft.digest` → `ContentPackage.digest` → `WechatDocument.digest`，模型层均为 `str = ""`、无长度约束。

**自动生成**：`_make_digest()`（`core/workflow/pipeline.py`）取正文第一段非标题、非图片的文本行，剥离 Markdown 字符后截断 **54 字**（`_DIGEST_MAX_CHARS`，保守值）。

**平台限制**：摘要最长 120 字（以草稿箱接口为准）。管线只强制 54 字截断，手写摘要建议同样不超过此长度。

**手写时机**：自动摘要适合事实类内容；观点文、深度文建议在 `ArticleDraft.digest` 手写——一句话回答「读者点开能得到什么」，直接对齐 `ContentBrief.goal`。摘要展示在会话分享卡片与搜索结果里：写成通顺的承诺句、含主关键词，不是关键词罗列。

## 三、关键词

本项目**没有独立的 keywords 字段**——关键词由既有字段承载，不新增概念：

| 载体 | 字段 | 用法 |
|------|------|------|
| 主关键词 | `ContentBrief.topic` | 选题即定主词，标题必含 |
| 次关键词 | `ContentBrief.goal` / `audience` | 「写给谁、解决什么」自然带出 2-3 个次词 |
| 结构关键词 | `BriefSection.heading` | 章节标题用具体名词短语（如「三步配置缓存」），不用「第一节」 |

**操作约束**：

1. 选题阶段定 1 个主关键词 + 2-3 个次关键词；
2. 主关键词进标题、摘要、至少一个章节标题；
3. 正文自然覆盖，**不做密度堆砌**——堆砌的确定代价（可读性崩坏、AI 味分数下降）大于不确定的收益；
4. 关键词复读会触发 humanize 检测的 repetition 惩罚（5 字 n-gram 出现 ≥ 3 次即 warning、扣 5 分）——机器恰好站在堆砌的对立面。

## 四、搜一搜收录

收录与排序由微信平台决定，官方未公开完整算法。诚实地区分两类：

**相对确定（平台公开引导过的方向）**：

- 标题、摘要含搜索词是召回的基础匹配；
- 原创声明状态在正式发布链路可观测：`release()` 的 publish_state=2 即「原创申明失败」（见 [../skills/publishing/SKILL.md](../skills/publishing/SKILL.md)）；原创标记是否生效取决于账号权限与文章设置；
- 账号维度的稳定更新频率。

**不确定（不要当承诺）**：

- 具体排名因子的权重；
- 新文的收录时效；
- 任何「保证收录 / 保证排名」的说法。

**Agent 行动边界**：把标题、摘要、关键词三件事做扎实，正式发布如实暴露原创申明状态；**绝不向用户承诺搜一搜排名或收录结果**（H5 精神：无 PASS 裁决，不做承诺）。
