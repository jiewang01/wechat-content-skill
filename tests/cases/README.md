## 验收指标（选自 plan §3.6）

- 字段提取完整率（ad-task 必填项 / 出现项）
- 金额提取准确率（固定费 / 佣金 / 置换 / 未报价 four 态）
- 截止时间识别准确率（明确 / 相对 / 未写）
- mandatory / optional / forbidden 识别准确率
- **unknown 识别能力：不把"没写"当"没有"**（重点：revision_limit、estimated_hours）
