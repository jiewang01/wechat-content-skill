# Content Strategy 规则

> 来源：plan §5.2
> 版本：v1

## 1. 原则

不要 AI 直接写广告。先生成 **3 个候选内容方向**，再依据匹配度选择生产方向。

## 2. 三角度生成框架

| 角度 | 特征 | 适用 |
|---|---|---|
| Angle A — 人群共鸣 | 从 target_audience 痛点切入 | 高品牌 fit / 账号人群重合度高 |
| Angle B — 产品差异 | 从 product_usp 单点放大 | key_messages 明确 / 有可验证点 |
| Angle C — 场景植入 | 从使用场景/开箱/对比切入 | 账号有历史同类内容 |

## 3. 选择规则

```text
选择分 = 0.4×Account Fit 子项 + 0.3×Historical 表现 + 0.3×生产成本(拍摄/字数)
```

- 历史同类内容表现好 ⇒ 优先 Angle 与历史一致的选项。
- 生产限制（无外出拍摄、字数受限）⇒ 排除高生产成本角度。
- 最终输出：`content_angle`（选定角度）+ 备选角度列表。

## 4. 输出约束

- 每个角度必须一句话说明理由，并引用相关 Evidence。
- 禁止直接产出整篇文案（那是 Draft Generator 的职责）。
