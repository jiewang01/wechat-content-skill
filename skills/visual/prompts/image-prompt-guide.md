# 图片提示词指南（visual/prompts/image-prompt-guide.md）

> VisualPlan 中 `cover.prompt` / `images[].prompt` 的写法。提示词会原样交给图片 provider，所以必须**自包含**——不得出现「如上文那种」「同前文风格」类指代。

## 提示词五要素

```text
[主体] + [风格] + [构图/比例] + [色调] + [约束]
```

示例（封面，editorial 风格）：

> 极简编辑风插画：一张长桌上摊开的报纸被一只机械手翻页，报纸版面浮现代码块与聊天气泡；扁平矢量风格，大量留白，主色墨绿与米白，点缀橙色；横构图 2.35:1；无文字、无水印、无照片元素。

## 各 purpose 的写法

| purpose | 要素侧重 | 示例开头 |
|---------|----------|----------|
| `concept` | 隐喻要直白，一个图一个概念 | 「数据像水流过三道闸门…」 |
| `example` | 还原真实界面/场景，交代关键元素 | 「仿终端窗口，深色背景，光标停在报错行…」 |
| `screenshot` | 直接描述目标画面内容 | （尽量用真实截图，提示词写替代方案） |
| `mood` | 氛围与情绪，抽象但呼应章节基调 | 「清晨空旷的机房，一排指示灯亮着…」 |

## 硬规则

- **无文字原则**：图片内不要求出现可读文字（生成模型的文字渲染不可靠）；需要文字标注的图走 `diagrams`。
- **比例**：封面默认 `2.35:1`；正文插图默认 `16:9`；`ratio` 写进 prompt 末尾兜底。
- **风格锁定**：一篇文章所有 prompt 的风格描述保持一致（同色系、同画风），避免拼贴感。
- **密度**：每 600–900 字最多 1 张；`position` 指插入到第 N 节之前，不得超过章节数。
- **约束收尾**：每条 prompt 以「无文字、无水印」结尾，作为稳定负向约束。

## 机器归一化（optimize_prompt）

所有进入 `VisualPlan` 的 prompt——无论来自 design LLM 还是 imagery 确定性兜底——都会先经
`core/workflow/imagery.py::optimize_prompt` 归一，保证读者在 :::figure 占位卡片里看到的
prompt 可直接粘贴到任意文生图工具：

- 压平空白为单行，去掉尾部句读（`。；;`）；
- 缺画幅段时补齐（封面「横向封面构图（2.35:1），主体居中」/ 正文「横构图（16:9），视觉焦点居中」）；
- 缺负向约束时补主题 `negative`（无水印相关的段缺席才补）；
- 段间以「；」分隔、以「。」收尾。

归一是**幂等**的，且**不重写主体与风格措辞**：已合规的 prompt 再过一次结果不变。
因此 LLM 只需保证主体与风格质量，格式补齐交给管线。

## 降级路径（graceful degradation）

```text
图片 provider 生成失败
    → 换 prompt 重试 1 次（只改「风格」要素）
    → 图片搜索（以主体描述为查询词）
    → 占位图（纯色 + 主题色图形）
任一降级发生时置 VisualPlan.degraded = true
```

降级不阻塞管线：正文完整性优先于视觉完整性。
