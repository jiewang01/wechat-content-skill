# 句子工艺笔记（writing/style-basics.md）

> Humanize 检测器标红句子后的重写手册。目标：让句子像人写的，而不是像模型补全的。
> 规则阈值与扣分定义在 [humanize/rules.yaml](../humanize/rules.yaml)（H7：规则外置，改阈值不动代码）。

## 逐类修复对照

### blacklist_phrase（黑话 / 套话，-8 分/次）

| 检测到 | 改成 |
|--------|------|
| 首先我们来看 | （删掉，直接开始） |
| 值得注意的是 | （删掉，或改成事实本身） |
| 随着 X 的发展 | X 去年做了 Y（给具体） |
| 赋能 / 抓手 / 闭环 | 说功能本身：「帮你省掉一次手动导出」 |
| 总而言之 / 综上所述 | （删掉；结论直接说） |
| 让我们 | （删掉主语，直接动词开头） |

### paired_phrase（对仗套句，-8 分/句）

「不仅…而且…」「随着…的发展」「在这个…的时代」「扮演着…角色」整句重写：
把两个半句拆成两句，各自给一个具体事实。

### long_sentence（> 60 字单句，-3 分/句）

- 数并列项：超过三项就改列表（交给 native 层 `:::card`）。
- 拆从句：一个「的」超过两层就断句。
- 中文长句优先在动词前断开。

### avg_sentence_length（平均句长 > 35 字，-5 分/篇）

混入短句。观点句、转折句控制在 20 字内；每 3-4 个长句配一个 10 字内的短句当节拍。

### long_paragraph（> 200 字段落，-3 分/段）

一段只说一件事。超了就找「第二件事」从哪里开始，切两段。

### repetition（CJK 5-gram 重复 ≥ 3 次，-5 分/组)

同一个说法换了主语反复出现。合并成一次完整表述 + 后文用代词/简称。

## 通用手艺

- **动词开头**：「配置文件位于…」优于「配置文件是位于…的」。
- **数字具体化**：「大幅提升」→「从 8.2s 降到 1.4s」；没有数字就不许写「大幅」。
- **删零度词**：「非常」「十分」「进行了」「作出了」「一定程度上」基本都可删。
- **人称敢用**：公众号语境允许「你 / 我们」，比「用户 / 开发者」更近。
- **中文标点**：正文用全角标点；代码、命令、英文专名保留半角。

## 检测方式

```bash
python - <<'EOF'
from skills.content.humanize import analyze_text
report = analyze_text(open("draft.md", encoding="utf-8").read())
print(report.humanize_score, report.passed)
for issue in report.issues:
    print(issue["type"], issue["evidence"])
EOF
```

只有 `passed: true`（≥ 60 分）的稿件才能进入下一阶段（内容门，H5）。
