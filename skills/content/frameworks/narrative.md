# 框架：narrative（叙事文 / 非虚构故事）

> 适用：亲历故事、创业叙事、人物故事、非虚构写作。
> 输入：`ContentBrief`；输出：`ArticleDraft`（纯 Markdown，无 `:::` 标记）。

## 结构骨架

```text
1. 开场场景   —— 时间、地点、人物、动作；进行时态直接切入
2. 铺垫与张力 —— 主角想要什么 × 什么在阻止；读者始终知道赌注
3. 转折与展开 —— 关键场景放慢写：对话、细节、决定的瞬间
4. 结果与回响 —— 事情怎么了 + 这件事对人留下的改变
5. 留白结尾   —— 一个具体画面收尾，不总结中心思想
```

## 写作规则

- **场景而非摘要**：写「他第三次刷新了页面」，不写「他很焦虑」。
- **张力明确**：每一节读者都知道主角要什么、障碍是什么；没有赌注的段落删掉。
- **对话有功能**：每句对话推进信息或关系；寒暄和客套全删。
- **时间锚点**：写「2023 年 3 月」「上线前一夜」，不写「早期」「后来」。
- **节奏控制**：关键时刻放慢（分钟级细节），过渡时段加速（一句话跨三月）。
- **非虚构纪律**：不虚构未发生的对话；细节不可考时注明（如「记忆可能不准」）。

## 字数预算（word_target 参考）

| 部位 | 占比 |
|------|------|
| 开场场景 | 10% |
| 铺垫与张力 | 25% |
| 转折与展开 | 40% |
| 结果与回响 | 15% |
| 留白结尾 | 10% |

## 自审清单（批判 → 重写阶段逐项过）

- [ ] 开场 100 字内有具体场景吗（不是背景介绍）？
- [ ] 读者在任何一节都知道主角想要什么吗？
- [ ] 关键时刻放慢了、过渡时段加速了吗？
- [ ] 结尾是画面而不是道理吗？删掉最后一段的「感悟」，故事更完整吗？
- [ ] 每个细节都有出处，或标注了记忆的不确定性吗？
- [ ] 跑过 humanize 检测器，`passed: true` 了吗？

## Humanize 专项提示

叙事文最容易踩的 AI 味：「那一刻，他明白了…」的假高潮，「岁月静好」式抒情收尾。改法：情绪藏在动作和细节里——不写「她很感动」，写「她把那封邮件转发到了只给自己看的标签页」；结尾停在画面上，把领悟留给读者。
