# 广告友好型文章模版

## 适用场景

适用于品牌合作、产品推广、联盟营销等需要插入广告位的文章内容创作。

## 结构骨架

### 1. 标题 (Title)
- **字数**: 20-35 字
- **目标**: 吸引点击，明确价值
- **建议**: 突出痛点或利益点

### 2. 痛点 (Pain Points)
- **字数**: 200-400 字
- **目标**: 引发共鸣，建立问题意识
- **要点**:
  - 描述具体困扰场景
  - 量化负面影响
  - 暗示解决方案的必要性

:::callout type="info" title="广告位建议：位置 1"
在此处插入 Banner 广告或原生推荐卡片
:::

### 3. 真实案例 (Real Case Study)
- **字数**: 400-600 字
- **目标**: 用实际证据增强可信度
- **要点**:
  - 真实人物或公司背景
  - 面临的问题与目标
  - 关键转折点
  - 量化成果（数据需标注事实引用）

### 4. 解决方案 (Solution)
- **字数**: 400-600 字
- **目标**: 提供可行路径
- **要点**:
  - 方法论/流程拆解
  - 关键步骤说明
  - 常见误区提醒

:::callout type="warning" title="广告位建议：位置 2"
在此处插入产品对比表或工具推荐列表
:::

### 5. 工具 (Tools & Resources)
- **字数**: 300-500 字
- **目标**: 提供实操资源
- **格式**: Listicle 风格清单体
- **要点**:
  - 工具名称 + 核心功能
  - 优缺点对比
  - 价格区间
  - 适用人群

:::card title="广告位建议：位置 3 - 精选推荐" footer="数据来源自实际测试"
在此处插入主推产品的深度介绍或限时优惠信息
:::

### 6. 广告位 (Ad Placement)
- **可选插入类型**:
  - Banner 广告（宽度 728px 或响应式）
  - 原生内容推荐卡片
  - CTA 按钮（行动号召）
  - 产品演示视频
  - 限时优惠弹窗
  
- **最佳实践**:
  - 广告内容与文章主题强相关
  - 明确标识"广告"或"合作"
  - 控制在总内容的 15%-20%
  - 不影响阅读体验

:::note
广告插入原则：解决问题 → 展示方案 → 自然引入产品
:::

### 7. 总结 (Conclusion)
- **字数**: 200-300 字
- **目标**: 强化核心观点，给出下一步行动建议
- **要点**:
  - 回顾核心价值主张
  - 总结关键收获
  - 行动呼吁（CTA）

:::quote cite="你的署名，年份"
可以用一句话金句作为结尾，留给读者深刻印象
:::

## 交付标准

### 内容完整度检查清单
- [ ] 标题具有吸引力且不超过 35 字
- [ ] 痛点描述具体可感知
- [ ] 案例有量化数据和事实引用
- [ ] 解决方案步骤清晰可执行
- [ ] 工具清单提供实用价值
- [ ] 广告位自然融入内容流
- [ ] 总结有力且有行动指引

### 事实引用规则
- 所有数据必须标注 `fact_id` 引用来源
- 产品评价需注明主观/客观属性
- 第三方引用需保留原始出处

### 广告合规要求
- 明确标注商业合作性质
- 避免夸大宣传用语
- 提供足够的事实支撑
- 符合平台广告政策

## 注意事项

1. **广告密度控制**: 全文广告内容占比不超过 20%，避免影响用户体验

2. **相关性优先**: 选择与文章主题高度相关的广告内容，提升转化率

3. **时间敏感性**: 时效性强的广告（如促销活动）需及时更新

4. **数据追踪**: 为不同广告位设置独立追踪参数，便于效果分析

5. **移动端优化**: 确保广告在所有设备尺寸下正常显示
