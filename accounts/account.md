# 账号定位文档

## 核心定位

**「普通人的 AI + 效率生活指南 + 财富自由」**

### 一句话价值主张

每天解决一个工作、生活中的小问题。

### 内容原则

**不是:**  
"OpenAI 最新发布了什么。"

**而是:**  
"这个工作如果还在手动做，真的太浪费时间了。"

                     │
     ┌───────┬───────┼───────┬───────┐
     ▼       ▼       ▼       ▼       ▼

   写作工具 SaaS     耳机    编程课   企业服务

### 广告策略说明

- **核心理念**: 不是为了一个广告去做内容，而是账号的用户天然就是大量广告主想触达的人群。
- **适配度高**: 账号定位覆盖多个广告品类，为未来商业化预留充足空间。

## 标题方法论

### 错误示范 → 正确示范对比

| ❌ 不要这样 | ✅ 要这样 |
|------------|----------|
| GPT-5.6 新功能介绍 | 如果你每天写周报，建议把这个 AI 工作流存下来 |
| 5 款 AI 办公软件推荐 | 这 5 个工具，能把我一天的杂活压缩到 1 小时 |
| Mac 隐藏功能 | Mac 这几个设置不改，真的浪费了一台电脑 |
| Excel 技巧 | 每天整理 Excel 的人，建议把这个方法学会 |
| 免费网盘推荐 | 文件超过 10GB 以后，我终于找到一个不折腾的方法 |

### 标题公式

```
用户痛点 
+ 
具体场景 
+ 
结果 
+ 
工具
```

### 公式解析

1. **用户痛点** - 描述一个真实困扰（如"每天写周报"）
2. **具体场景** - 限定使用情境（如"如果你..."）
3. **结果承诺** - 给出预期收益（如"建议把这个...存下来"）
4. **工具暗示** - 提供解决方案载体（如"AI 工作流"）

### 创作检查清单

- [ ] 是否直击具体痛点而非泛泛而谈
- [ ] 是否有明确的适用场景
- [ ] 是否给出可量化的结果承诺
- [ ] 是否避免了技术术语堆砌
- [ ] 是否能让读者立刻想到自己的需求

## 执行建议

### 发布节奏

- **不要一上来什么都发**
- 围绕核心支柱逐步建立内容矩阵
- 前期聚焦 AI 和效率两大方向
- 中期引入工具和数码品类
- 后期完善省钱和资源栏目

### 内容验证标准

每个选题发布前问自己三个问题：

1. 这个问题是否足够日常和普遍？
2. 解决方案是否能用图文清晰展示？
3. 读者看完后能否立即动手尝试？

### 商业化节点

当粉丝达到一定基数后，按优先级接洽以下类别广告：

1. AI 工具类（最契合内容调性）
2. 办公软件/SaaS 类（与办公效率强相关）
3. 教育课程类（用户愿为技能提升付费）
4. 硬件数码类（高客单价产品）
5. 生活服务类（长期变现方向）
